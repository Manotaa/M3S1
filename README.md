This project corresponds to M3S1 – Interactive Messaging System and was developed in JavaScript to demonstrate fundamental programming concepts through user interaction and data validation. The application requests the user's name and age using the prompt() function, converts the age input into a numeric value, and validates that the entered information is a valid number before continuing. If the user provides invalid input, the program displays an error message using console.error() to prevent incorrect data from being processed. Once the age is successfully validated, the system uses conditional statements (if and else) to determine whether the user is a minor or an adult and then displays a personalized message through both console.log() and alert(). The code follows modern JavaScript best practices by using const for variable declarations, descriptive variable names, and clear comments to improve readability and maintainability. This project reinforces essential JavaScript concepts including user input handling, data type conversion, conditional logic, error handling, browser interaction, and code organization, providing a solid foundation for developing more advanced interactive web applications.
